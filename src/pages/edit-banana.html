Frequently Asked Questions

What model is this using?

Google's Gemini image-editing model (informally "Nano Banana"). ChamPDF wraps the API and adds a focused UI for common edits.

How is this different from the PDF Watermark Remover?

The PDF Watermark Remover is mask-based — you draw a rectangle around the watermark and the model only changes that area. Edit Banana is prompt-based — you describe what you want and the model edits anything in the image to match. Different jobs.

Why does my edit sometimes refuse to run?

Gemini has safety filters and will refuse some prompts. If a request is declined, the model's reason is shown. Reword the prompt or pick a different image.

Are my images stored?

No. The original and the edit are streamed through our backend and deleted as soon as the response completes. We don't keep copies.
